# Pounds ↔ Kilograms Converter

Lightweight static converter. Open `index.html` in a browser to use.

Files:
- `index.html` — main page
- `styles.css` — simple styling
- `script.js` — conversion logic

Usage:
1. Open `index.html` in your browser (double-click or serve with a static server).
2. Type a value in either the Pounds or Kilograms field; the other updates live.

No dependencies or build steps required.
